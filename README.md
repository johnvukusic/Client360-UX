# Case Study: Client360 (BNY)

**Project Goal:** Track and display onboarding progress for external and internal users.

**Key UX Contributions:**

-Designed intuitive dashboard with progress indicators.

-Streamlined document upload process for clients.

-Integrated feedback loops to improve client experience.

**Tools Used**: Figma, Axure, JIRA, Confluence

**Outcome:**

Reduced client onboarding time by 30%.

Achieved a 95% satisfaction rate in post-launch surveys.
